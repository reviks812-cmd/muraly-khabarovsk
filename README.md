# Муралы Хабаровска

Статический сайт-каталог уличных росписей Хабаровска: истории, авторы, адреса, карта, маршруты и галерея.

## Как открыть

**На компьютере:** откройте `index.html` двойным щелчком. Сайт работает без сервера.

**На телефоне:** есть два способа.

1. Скопируйте всю папку на телефон и откройте `index.html` в браузере.
2. Запустите сервер на компьютере и зайдите с телефона по адресу из консоли:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

Для доступа по Wi-Fi запустите PowerShell **от имени администратора**. Скрипт напечатает адрес вида `http://192.168.1.10:8099/` — откройте его на телефоне. Компьютер и телефон должны быть в одной сети; при запросе разрешите PowerShell в брандмауэре Windows.

## Публикация в интернете (GitHub Pages)

Сайт статический, поэтому его можно бесплатно опубликовать на GitHub Pages.

1. Зарегистрируйтесь на github.com.
2. Создайте публичный репозиторий, например `muraly-khabarovsk`.
3. На странице пустого репозитория выберите **uploading an existing file** и перетащите **содержимое** папки `github-upload` (не саму папку), чтобы `index.html` оказался в корне репозитория.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
6. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/muraly-khabarovsk/`.

Все ссылки в проекте относительные, поэтому сайт корректно работает и в подпапке.

Netlify (`*.netlify.app`) в России часто блокируется или обрывает соединение — из-за этого CSS и скрипты могут не загружаться, и страница выглядит «голой». GitHub Pages в этом смысле надёжнее.

## Страницы

- `index.html` — главная: hero-коллаж, цифры проекта, подборка муралов.
- `murals.html` — каталог из 8 работ с фильтром по районам, поиском и модальными историями.
- `history.html` — хронология 2018–2025, словарь терминов и FAQ.
- `map.html` — стилизованная карта с 8 точками, списком локаций и карточкой мурала.
- `routes.html` — 4 пешеходных маршрута с остановками.
- `gallery.html` — галерея с фильтрами и полноэкранным просмотром (стрелки, Esc).

## Мобильная версия

- Адаптив от 320px: одна колонка, уменьшенные заголовки без переносов и обрезания.
- Бургер-меню с прокруткой на низких экранах, блокировкой фона и закрытием по ссылке.
- Фильтры прокручиваются горизонтально, карточки и модальные окна занимают весь экран.
- На экранах до 460px кнопка «На карту» в шапке скрыта, чтобы не теснить логотип и меню.
- Все интерактивные элементы работают по нажатию; у точек карты увеличена зона попадания.

## Структура

```
index.html, murals.html, history.html, map.html, routes.html, gallery.html
css/style.css

img/mural-*.svg — иллюстрации работ
server.ps1      — локальный сервер (в том числе для телефона)
```

## Важно

Это демо-проект: иллюстрации, имена художников, истории и адреса придуманы для примера. Шрифты Unbounded и Manrope подключаются с Google Fonts; без интернета используются системные аналоги.
